01 / FLAGSHIP PERSONAL ENGINEERING PROJECT

OBSERVABILITY · INCIDENT INTELLIGENCE

Pipeline Sentinel

View source ↗

A self-diagnosing pipeline observability platform that turns scattered workflow signals into correlated incidents and evidence-led investigation.

PIPELINE INCIDENT LIFECYCLESELECT A COMPONENT TO EXPLORE
COMPONENT DETAIL

Airflow orchestrates four monitored workflows: orders_ingest, customers_dim, payments_etl and daily_revenue_agg. Successful runs establish the baseline for anomaly detection.

POSTGRESQL metadata & incidentsPROMETHEUS metricsGRAFANA observabilityLANDER event ingestion

THE PROBLEM

Pipeline failures, late data, schema changes and unexpected volume shifts can appear as separate symptoms. Investigating each alert in isolation makes it harder to understand the incident and its downstream impact.

THE ENGINEERING

Built a Docker Compose environment around Airflow, Redpanda, PostgreSQL, FastAPI and Prometheus/Grafana. Python services collect signals, detect anomalies, correlate findings and gather diagnostic evidence.

THE SAFETY MODEL

Controlled fault injection exercises the detection path. Diagnosis evidence is separated from recovery actions; retry behavior is designed around allowlisting and auditability rather than unrestricted automation.

ENTERPRISE INGESTION · CLOUD AUTOMATION

SharePoint-to-S3 Extraction Framework

CLIENT DETAILS OMITTED

A Python-based enterprise extraction framework developed as part of my TCS role to move documents from nested SharePoint libraries into Amazon S3 with state tracking and resilient processing.

SOURCESharePointNested libraries & folders
EXTRACTPython workersREST API, later Graph API
PROCESSDocument pipelineConversion & metadata
DESTINATIONAmazon S3Files & metadata.json

FRAMEWORK DESIGN

Built recursive nested-folder traversal, Python extraction and S3 upload flows, metadata-based extraction state, document conversion (including PPTX-to-PDF) and asynchronous processing on ECS Fargate.

API EVOLUTION

The initial implementation integrated with SharePoint REST APIs. The integration later evolved to Microsoft Graph API. This was a migration during the project's lifecycle, not the original implementation.

RELIABILITY WORK

Addressed inconsistent file counts across repeated runs and memory pressure on ECS Fargate. Added concurrency controls using semaphores and locks, alongside state tracking and error handling.

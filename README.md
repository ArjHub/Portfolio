# Portfolio
Place these files from your existing repo before deploying:
- `assets/profile.png`  (your portrait; lowercase name, ~800x1000px, under 200 KB)
- `Resume.pdf`          (repo root, next to index.html)

Deploy: commit all files to GitHub main; Vercel auto-deploys (no build command, output dir = root).

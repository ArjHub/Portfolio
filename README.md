# Arjun P — Engineering Portfolio

A responsive, static HTML/CSS/JavaScript portfolio focused on cloud data engineering, data platforms and pipeline reliability.

## Structure

- `index.html` — portfolio content and interactive architecture explorer
- `style.css` — design system, responsive layouts and light/dark themes
- `script.js` — navigation, theme toggle, architecture detail and copy-email interactions
- `assets/` — portfolio assets
- `Resume.pdf` — downloadable resume (keep this file current before publishing)

## Local preview

Open `index.html` directly, or serve the repository root with any static HTTP server. No package install or build step is required.

## Deploy

The site is static and can be deployed from the repository root on Vercel. Set the framework preset to **Other**, leave the build command empty, and use `.` as the output directory. Connect the custom domain in Vercel only after confirming its DNS configuration.
